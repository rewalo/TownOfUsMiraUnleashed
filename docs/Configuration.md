# Configuration

## Role and modifier options

All gameplay options are configured in-game through the lobby settings UI under each role or modifier's group (Roles tab for roles, Modifiers tab for modifiers). See each role's page for the full option list and defaults.

## Local settings

Mira Unleashed adds a **Mira Unleashed** tab to the local (per-client) settings, currently containing:

| Setting | Effect |
| --- | --- |
| Nausea Camera Shake | When enabled, the Injector's Nausea effect shakes your camera. Disable if motion sensitive. |
| Clueless Censor Type | How your own hidden task text is rendered when you are Clueless: White Bars, Asterisks, Question Marks, or Remove (clears the task text). Default Asterisks. |

## Config file

`BepInEx/config/rewalo.mira.unleashed.cfg` holds BepInEx-level settings only.
