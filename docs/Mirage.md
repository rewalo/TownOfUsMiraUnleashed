# Mirage

![Mirage](assets/RoleHeaders/Mirage.png)

- **Team:** Crewmate
- **Alignment:** Crewmate Support
- **Colour:** #DEA85E (crewmate blue when "Use Crewmate Team Color" is on)

## Overview

The Mirage is a Crewmate Support role that can place a decoy with the appearance of a chosen target (yourself or a random player). If any player interacts with the decoy, it disappears instantly and both the Mirage and the toucher receive a notification.

## Abilities

| Ability | Description |
| --- | --- |
| Decoy | Prime to prepare a decoy for placement. Press again to place the decoy. While active, the button becomes Destroy. |

## Options

| Option | Range | Default |
| --- | --- | --- |
| Initial Uses | 1 – 15 | 4 |
| Uses Per Tasks | Off, 1 – 15 | Off |
| Decoy Cooldown | 1 – 60 s | 25 s |
| Auto Destroy Cooldown | Off, 1 – 60 s | Off |
| Decoy Type | Mirage / Random Player | Random Player |
| Arrow Time | 0 – 15 s | 6 s |
| Arrow Target | Mirage / Interactor | Interactor |

## Interactions & notes

- Mirage cannot be guessed while the placed decoy has the Mirage's own appearance (choose the "Mirage" decoy type for this protection).
- When the decoy is triggered, the Mirage gets an arrow to the configured target (the interactor or the Mirage themselves).
