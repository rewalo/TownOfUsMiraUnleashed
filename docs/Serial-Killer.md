# Serial Killer

![Serial Killer](assets/RoleHeaders/Serial Killer.png)

- **Team:** Neutral
- **Alignment:** Neutral Killing
- **Colour:** #3A66C0 — always, even with "Use Crewmate Team Color" enabled

## Overview

The Serial Killer is a Neutral Killing role whose only objective is to kill everyone and win alone. The Serial Killer can optionally kill players who are in vents with them, but loses the ability to vent for the rest of the game after doing so.

## Abilities

| Ability | Description |
| --- | --- |
| Kill | Standard kill button with impostor vision and venting. |

## Options

| Option | Range | Default |
| --- | --- | --- |
| Can Report Bodies | On / Off | Off |
| Vent Kill Targets | Impostors / Impostors + Neutral Killers / Impostors + Neutrals / Any | Any |
| Maniac Mode | On / Off | On |
| Maniac Timer | 5 – 60 s | 40 s |
| Kill Cooldown | 0 – 30 s | 19 s |

## Interactions & notes

- In **Maniac Mode**, a timer runs between kills; killing resets it and grants the kill cooldown. If the timer expires, the Serial Killer dies.
- With report disabled, the Serial Killer cannot report bodies.
- Vent kills remove vent access for the rest of the game.
